# 我的账本 · 微信记账小程序

一款浅色磨砂玻璃风格的微信记账小程序。原生小程序开发，自定义 TabBar，wx.storage 本地持久化。

- 明细：按日期分组的收支流水 + 月度概览卡
- 记一笔：支出/收入切换、12 个内置分类、自动限两位小数
- 统计：按月筛选、分类占比排行与进度条
- 详情：查看单笔、支持删除

技术栈：WXML / WXSS / JavaScript，自定义 TabBar，GSAP 动效原则迁移（无 DOM 环境）。
设计系统见 DESIGN.md。导入微信开发者工具即可运行（AppID 选测试号）。
